- **바탕**: 순백이 아닌 아주 옅은 웜 화이트 `#FFFFF8`. 면 구분은 `#F0F5F3`·`#E9EBE6` 같은 옅은 회녹색 톤으로만 한다.
- **글자색**: 순흑 대신 짙은 차콜 `#232323`. 보조 텍스트는 `#686866`, 괘선은 `#C7C7C2` 정도의 회색이다.
- **포인트 색 1, 블루**: 하늘색 `#5DACED`(인쇄 기준 `#5DA2FF`). 제목 두 번째 줄, 목차 괘선, 화살표에만 쓴다. 연한 톤은 `#A9CEFF`·`#DDECF4`.
- **포인트 색 2, 오렌지**: `#E87536`(연한 톤 `#F2B490`). '느리고 비싼 사고(사람 판단)'를 뜻하고, 블루는 '정리되어 빨라진 것(코드·가중치)'을 뜻한다. 색이 곧 의미다.
- **타이포**: 산세리프(그로테스크) 한 종류만 쓴다. 표지 제목은 아주 크게(약 60pt) Light/Regular로 쓰고 굵게 하지 않는다. 앞 단어는 차콜, 뒷부분은 블루로 나눈다(예: "AutoResearch **and the Fine-Tuning Ontology**").
- **위계**: 본문은 작은 크기(약 9–10pt)에 넉넉한 줄간격. 소제목은 Medium 굵기로만 구분하고 밑줄·박스는 쓰지 않는다.
- **표지**: 좌상단에 작은 Palantir 로고, 큰 제목, 짧은 부제가 있다. 하단 절반은 가는 블루 수평선을 계단식으로 쌓은 추상 그래픽(데이터 흐름이나 막대 차트 느낌)이고, 맨 아래에 아주 작은 저작권 문구가 있다.
- **섹션 표지**: 큰 숫자(1, 2, 3, 3.1)와 3–5줄로 끊은 큰 제목만 둔 여백 위주의 페이지.
- **레이아웃**: 넓은 여백, 2단 비대칭 그리드. 좌측 좁은 열에 라벨(예: "Accelerated Compounding"), 우측 넓은 열에 본문이 오고 항목 사이를 얇은 가로 괘선으로 나눈다.
- **목차**: 큰 장 제목 + 위첨자 번호 [1] + 얇은 블루 괘선 + "→ 항목" 목록.
- **다이어그램**: 아이소메트릭 선화(블루 라인 + 옅은 블루 면)로 그린 레이어 스택, 번호 붙은 단계(01–05) 라벨, 가는 화살표 루프. 그림자·그라데이션·3D 광택은 없다.
- **차트/플로우**: 직사각형 박스 + 1px 선 + 작은 대문자 라벨. 두 열 비교(SLOWER/FASTER), 중첩 루프, 동심원(줄어드는 결정 면적) 같은 개념도가 중심이다. 실제 수치 그래프는 거의 없다.
- **하단**: 페이지마다 작은 로고와 쪽 번호만 둔다.
- **사이트 적용 1, 색**: 지금의 흰 배경과 검은 글자를 유지한다. 원하면 배경 `#FFFFF8`, 글자 `#232323`로 부드럽게 바꾸고, 강조색은 블루 하나만 쓴다(링크·제목 일부·괘선). 오렌지는 '진행 중/생각 중'처럼 의미가 있을 때만 쓴다.
- **사이트 적용 2, 레이아웃과 시각화**: 항목 페이지는 '좌측 라벨 + 우측 본문' 2단, 섹션 사이는 1px 괘선으로 나눈다. 시각화(타임라인·마인드맵)는 선화 스타일로 하고 카드 그림자·둥근 모서리는 줄인다. 큰 제목은 Light 굵기에 두 톤으로 나눈다.
